Cómo funciona

Crea alerta. Recibe licitaciones en tu email.

# 1. Crear alerta licitalert add-alert --name "Software Colombia" \ --countries co \ --keywords "software,desarrollo,sistemas" \ --email yo@empresa.com # Output: ✓ Alerta creada: RULE-A1B2C3D4 - Software Colombia Países: ['co'] Keywords: ['software', 'desarrollo', 'sistemas'] # 2. El scheduler corre cada 6 horas automáticamente. Force check: licitalert check-now # Output: Ejecutando ciclo de check... ✓ Done Nuevas licitaciones: 47 Matches: 3 Notificaciones enviadas: 1 # 3. Recibes email con tabla HTML: # Asunto: 🔔 LicitAlert: 3 licitaciones nuevas ┌──────┬──────────────────────────────────────────┬──────────────────────┬──────────────┬───────┐ │ País │ Título │ Entidad │ Presupuesto │ Score │ ├──────┼──────────────────────────────────────────┼──────────────────────┼──────────────┼───────┤ │ CO │ Desarrollo sistema gestión integral │ Ministerio Tecnología│ $50,000,000 │ 100% │ │ CO │ Software para entidad X │ Alcaldía Municipal │ $25,000,000 │ 67% │ │ CO │ Plataforma digital ciudadana │ Gobernación │ $80,000,000 │ 33% │ └──────┴──────────────────────────────────────────┴──────────────────────┴──────────────┴───────┘ # 4. Vía API: curl -X POST http://localhost:8009/v1/rules -d '{ "name":"Construcción LatAm", "countries":["co","mx"], "keywords":["construccion","obra"], "min_budget":1000000, "alert_channels":["email"], "alert_recipient":"yo@x.com" }'
