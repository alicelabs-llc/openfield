Cómo funciona

Cliente escanea. Ve menú. Pide. Cocina recibe.

# 1. Configura tu menú (una sola vez) menuqr add-category --id entradas --name "Entradas" --sort 0 menuqr add-category --id principales --name "Principales" --sort 1 menuqr add-item --category entradas --name "Ceviche" --price 8.50 --desc "Pescado fresco" menuqr add-item --category principales --name "Lomo Saltado" --price 14.00 # 2. Agrega tus mesas menuqr add-table --number 1 --capacity 4 --location interior # → Mesa 1: TBL-A1B2C3D4 # 3. Genera QR para imprimir menuqr qr TBL-A1B2C3D4 --out mesa1.png # 4. Cliente escanea QR → ve menú en su celular → hace pedido curl -X POST "http://localhost:8008/public/order?table_id=TBL-A1B2C3D4¬es=sin cebolla" \ -d '[{"item_id":"ITM-001","qty":2},{"item_id":"ITM-002","qty":1}]' # Response: { "id": "ORD-X1Y2Z3", "table_number": 1, "items": [{"item_id":"ITM-001", "qty":2}, ...], "total": "37.00", "status": "pending" } # 5. Cocina ve el pedido y actualiza estado: curl -X POST "http://localhost:8008/admin/orders/ORD-X1Y2Z3W3/status?status=preparing" curl -X POST "http://localhost:8008/admin/orders/ORD-X1Y2Z3W3/status?status=served" # 6. Tú ves todos los pedidos desde CLI: menuqr list-orders # → ORD-X1Y2Z3 | Mesa 1 | 3 items | $37.00 | preparing | 14:32
