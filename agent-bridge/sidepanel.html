🤖 Agent Bridge

Securely control your browser via GitHub + webhook.site. No tokens, no ports.
⚪ Disconnected
How it works:
1. Click Connect
2. Agent sends commands via GitHub (public repo, no auth needed)
3. This extension polls every 2s and executes them
4. Responses go back via webhook.site (no auth needed)

Security: Agent never sees your passwords. You control the connection — disconnect any time. Only the active tab is controlled.
