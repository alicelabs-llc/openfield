## Methodology notes

- **No fabricated hackathons.** Every URL above was fetched live on 2026-10-24 with curl or `agent-browser` (Playwright Chromium). Each Devpost URL returned HTTP 200.
- **Date cutoff:** Today is 2026-10-24 00:24 UTC. "Deadline AFTER Oct 23, 2026" interpreted as deadline ≥ Oct 24, 2026.
- **Prize threshold:** >$500 USD equivalent. EUR prizes at €997 included (borderline). USDG/USDC treated as USD-equivalent.
- **Eligibility:** "Worldwide" verified by inspecting each Devpost page's `Region` JSON field (empty = worldwide) and Herox restricted-jurisdictions list. Ecuador confirmed NOT in restricted list for Blaise xTech (only US-sanctioned + a few others listed).
- **Topcoder v6 API caveat:** Lightweight response shows `totalPrize: 0` for all 3 active challenges — this is an API bug, not a real $0 prize. Topcoder dev challenges typically have $1K-$5K prizes but require authentication to view. Recommend manual browse at topcoder.com/challenges after login.
- **DoraHacks blocked:** Could not enumerate. Recommend manual browse from Ecuador residential IP (the WAF challenge is IP-based, not policy-based).
