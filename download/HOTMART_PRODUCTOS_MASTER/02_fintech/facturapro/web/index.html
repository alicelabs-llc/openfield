Cómo funciona

5 endpoints. Una factura autorizada.

Flujo completo: crear → firmar → enviar → autorizar → descargar PDF.

# 1. Crear factura (genera XML + PDF + clave de acceso) curl -X POST http://localhost:8001/v1/factura/create \ -H "Content-Type: application/json" \ -d '{"cliente":{"ruc_cedula":"1712345670001","razon_social":"CLIENTE SAC","tipo_identificacion":"04"}, "detalles":[{"codigo_principal":"P001","descripcion":"Servicio","cantidad":2,"precio_unitario":100,"iva_tarifa":15}]}' # Response: { "clave_acceso": "251020240101001234567001200100100123456780000016", "secuencial": "001001000000001", "totales": {"importe_total": "230.00"}, "xml_path": "~/.facturapro/data/facturas/.../factura.xml", "pdf_path": "~/.facturapro/data/facturas/.../factura.pdf" } # 2. Firmar XML (XAdES-EPES envelope) curl -X POST http://localhost:8001/v1/factura/sign \ -d '{"xml":"..."}' # 3. Enviar al SRI (Ecuador) / PAC (México) curl -X POST http://localhost:8001/v1/factura/send-sri \ -d '{"xml_signed_b64":"..."}' # → {"success": true, "estado": "RECIBIDA"} # 4. Poll por autorización curl http://localhost:8001/v1/factura/authorize/251020240101001234567001200100100123456780000016 # → {"success": true, "estado": "AUTORIZADO", "numero_autorizacion": "..."} # 5. Descargar PDF curl -o factura.pdf http://localhost:8001/v1/factura/pdf/CLAVE_ACCESO
