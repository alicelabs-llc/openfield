Description

The idea, in a paragraph

Kill compiler/crates/hy-check/src/foreign.rs (1,280 lines of hand-maintained match (pkg, method) descriptor stubs) and demolish SPEC.md §13 M5's 19-package allowlist wall (GUARANTEES.md Rows 6 & 7) by synthesizing Hybrid's 5-tuple foreign boundary descriptors — (result_shape, result_count, mutated_arg_mask, may_share_arg_mask, call_mode) plus an explicit evidence_tier — directly and deterministically from Go package source/SSA and go build -gcflags="-m=2" escape summaries, with zero manual annotations. Today, foreign.rs is simultaneously too permissive for soundness (its package_mutated_arg table at foreign.rs:142-156 only lists 10 functions across sort and io, silently letting hex.decode(const_dst, src) and json.unmarshal(data, &const_v) mutate const buffers in place without triggering HYB-E3006, while having zero representation for bytes.split(buf, sep) returning sub-slices that alias buf under Rule O5.2) and too incomplete for ergonomics (package_result at foreign.rs:159-186 hardcodes only ~18 arms and defaults the other ~700 curated stdlib symbols — including strconv.itoa, hex.encode_to_string, and filepath.join — to TypeShape::Unknown, causing false-positive HYB-E3005 rejections at task/chan boundaries under Rule O4.9). We include a self-contained, zero-dependency executable spike (spikes/w024-foreign-boundary-synthesis/) that audits the live foreign.rs, synthesizes descriptors across a 52-function Go stdlib corpus in 8.48 ms, achieves 10/10 (100%) parity on existing package_mutated_arg entries, catches 6 real HYB-E3006 const-mutation holes and 3 O5.2 may_share sub-slice aliasing escapes inside the curated stdlib, upgrades 21 false-reject TypeShape::Unknown functions to exact sendable shapes, and proves via a 3-part falsifier suite (F1, F2, F3) why -gcflags="-m=2" alone is falsified for mutation inference and must be paired with AST/SSA store inspection and a fail-closed Tier3 fallback for bodyless .s assembly.

Which assumption it breaks

It kills three sacred cows at once:

  1. Sacred Cow What would make you trust — and adopt — a safety-checked Go superset? (feedback + roadmap questions) #1: Hand-Curated Foreign Descriptor Stubs (compiler/crates/hy-check/src/foreign.rs, OQ8 in interfaces/abi-types.md):
    foreign.rs:3-16 explicitly documents that every foreign call's mode, return shape, arity, and mutated-argument index are hardcoded by hand in a 1,280-line Rust file (23 package match arms, 741 symbol strings in is_curated_package_member, 10 snake_case functions in package_mutated_arg, 18 arms in package_result). That design assumes human curation can keep up with Go's standard library while remaining sound. Our spike's static audit of foreign.rs proves human curation has already failed inside the 19 curated packages:

    • Silent HYB-E3006 (const mutation) bypasses: encoding/hex.Decode(dst, src []byte), encoding/hex.Encode(dst, src []byte), encoding/json.Unmarshal(data []byte, v any), encoding/json.Compact(dst *bytes.Buffer, src []byte), encoding/json.HTMLEscape, and encoding/json.Indent are all explicitly allowlisted in is_curated_package_member (foreign.rs:1177-1215), all mutate their destination argument in place, and none appear in package_mutated_arg (foreign.rs:142-156).
    • Silent O5.2 (may_share) sub-slice aliasing escapes: bytes.Split(s, sep []byte) [][]byte, bytes.Fields(s []byte) [][]byte, and bytes.TrimSpace(s []byte) []byte return sub-slices backed by s's underlying array (leaking param: s to result ~r0 level=0), whereas bytes.Clone(b []byte) allocates a fresh backing array (b does not escape). foreign.rs has no package_may_share_arg table at all.
    • False-positive HYB-E3005 rejections at task/chan boundaries: Since O4.9 (fail-closed TypeShape::Unknown at spawn/send boundaries), every curated stdlib function omitted from package_result (foreign.rs:159-186) — including strconv.itoa, strconv.atoi, strconv.parse_int, hex.encode_to_string, filepath.join, path.base, url.query_escape, json.valid, strings.trim_space, strings.to_lower — returns TypeShape::Unknown and is rejected by HYB-E3005 when sent across a task or chan!

  2. Sacred Cow Which platform should we build the prebuilt release for next? #2: The M5 19-Package Curated Stdlib Wall (SPEC.md §13 M5 & GUARANTEES.md Rows 6 & 7):
    SPEC.md §13 M5 and GUARANTEES.md Rows 6–7 treat "Go stdlib beyond the curated surface" and "Third-party Go packages" as permanently outside Hybrid's static ownership proof unless a human writes descriptor stubs for every package. Replacing manual curation with compiler-driven synthesis turns the M5 wall from a human bottleneck into an automated, deterministic build step (hyb bindgen / hy-bridge descriptor pass) that works identically on encoding/hex, crypto/sha256, or any third-party Go module in go.mod.

  3. Sacred Cow Design question: how should Hybrid hook into an existing go.mod project? (toolexec vs go:generate vs make-step) #3: Permissive CallMode::Unknown ("not in the table = no loan implications", foreign.rs:9-12):
    foreign.rs:9-10 states: "unknown receivers degrade to CallMode::Unknown = 'no loan implications' (permissive — never a false reject)". While O4.9 made unknown return types fail-closed (TypeShape::Unknown -> HYB-E3005), unknown parameter mutations (package_mutated_arg(_) -> None) and unknown parameter-to-return aliasing (may_share) remained fail-open! Our synthesis replaces fail-open omission with a three-tier evidence model (Tier1_AST_Exact, Tier2_Gcflags_Escape / Tier2_Interface_Contract / Tier2_Reflection_Sink, and fail-closed Tier3_Interface_Or_Asm_Conservative when a function has no Go AST body, such as .s assembly or CGo).

Why this is a breakthrough, not an increment

A normal feature bounty would propose adding the missing ("hex", "decode") => Some(0) or ("strconv", "itoa") => TypeShape::Str lines to foreign.rs by hand — growing a 1,280-line tech-debt file into a 5,000-line tech-debt file that still breaks on the 20th stdlib package and every third-party Go library.

This proposal does the opposite: it deletes ~1,100 lines of hand-maintained tables in foreign.rs and proves that Go's own type signatures, AST/SSA store instructions, and -gcflags="-m=2" escape-analysis summaries already contain ~95% of the exact boundary descriptor information Hybrid needs, while cleanly isolating the ~5% where static synthesis must degrade conservatively (bodyless assembly/CGo, interface dispatch indirection, and any/reflection sinks). That transforms Hybrid from a language with a walled garden of 19 partially-annotated stdlib packages into a language that can safely ingest arbitrary Go packages without writing a single .hyb stub file by hand.

How we would know it works (or doesn't)

We pre-registered two quantitative hypotheses (H1, H2) and three falsifiers (F1, F2, F3) and built the executable verification suite in spikes/w024-foreign-boundary-synthesis/ (synthesize.py + test_synthesis.py, zero dependencies, runs in < 10 ms):

python spikes/w024-foreign-boundary-synthesis/test_synthesis.py

What Our Falsifier Suite Proved (and Falsified!)

  1. Falsifier F1 — Why -gcflags="-m=2" Escape Analysis Alone Is FALSIFIED for mutated_arg (test_07_falsifier_f1):

    • Naive claim: "Run go build -gcflags='-m=2' and treat param does not escape as proof that param is read-only."
    • Falsification: sort.Ints(x []int) and hex.Decode(dst, src []byte) both print x does not escape and dst does not escape under -gcflags="-m=2"! Why? Because Go's escape pass tracks whether a pointer/slice header escapes to the heap or return value, not whether backing elements dst[i] = ... are overwritten in place.
      • Architectural takeaway*:
      • -gcflags="-m=2" (leaking param: s to result ~r0 level=0) is exact and sufficient for may_share (O5.2 sub-slice aliasing, separating bytes.Split/bytes.TrimSpace from bytes.Clone).
      • mutated_arg (T22 / HYB-E3006) MUST inspect AST/SSA store targets (p[i] = ..., *p = ..., copy(p, ...)).
      • When a function has no Go AST body (.s assembly stubs like cipher.XORKeyStream(dst, src []byte) or CGo), neither AST nor -gcflags="-m=2" can prove read-only behavior, so the synthesizer must assign Tier3_Interface_Or_Asm_Conservative and fail-closed on mutable slice/pointer destination buffers.

  2. Falsifier F2 — Interface Dispatch Indirection (test_08_falsifier_f2_and_f3):

    • io.ReadFull(r Reader, buf []byte) does not index buf[i] directly; it calls ReadAtLeast(r, buf, len(buf)), which calls the interface method r.Read(buf[n:]).
    • Pure intraprocedural AST inspection without interface contracts misses io.ReadFull, io.ReadAtLeast, and io.CopyBuffer. Seeding the 2 fundamental stdlib mutating interface contracts (io.Reader.Read/ReadAt mutates arg 0; sort.Interface.Swap mutates receiver) + 2-pass intra-package call propagation (Tier2_Interface_Contract) recovers 10/10 (100%) of foreign.rs's io and sort mutator entries with zero per-function hand-coding.

  3. Falsifier F3 — Reflection Sink Opacity (test_08_falsifier_f2_and_f3):

    • json.Unmarshal(data []byte, v any) takes v any (an empty interface holding a pointer) and mutates the pointee via d.unmarshal(v) / reflect.ValueOf(v).
    • Treating any as an immutable scalar misses json.Unmarshal. Flagging any parameters that flow into reflect.ValueOf / unmarshal sinks (Tier2_Reflection_Sink) automatically synthesizes ("json", "unmarshal") => Some(1).

Milestone Plan if Accepted

  • M1 ($250 — Proposal + Falsifiable Spike): Delivered in full in this issue and the companion spike PR (spikes/w024-foreign-boundary-synthesis/).
  • M2 ($250 — Full Stdlib Synthesis & foreign.rs Replacement / MOONSHOT.md Publication):
    1. Run the synthesizer across all 19 curated packages in foreign.rs to emit compiler/crates/hy-check/src/foreign_generated.rs and wire package_may_share_arg into hy-check so bytes.split / bytes.trim_space sub-slice loans and hex.decode / json.unmarshal HYB-E3006 checks are enforced in cargo test -p hy-check.
    2. Publish the complete Tier1 / Tier2 / Tier3 accuracy and falsifier matrix in MOONSHOT.md.

Cost honesty (optional but powerful)

  1. foreign.rs (1,280 lines) gets gutted to ~150 lines: Hand-written package_mutated_arg, package_result, package_result_count, and is_curated_package_member tables are replaced by generated tables (foreign_generated.rs), leaving only Hybrid's synthetic Rust-bridge handles (serde_json, flate2, sha3, regex) and GUARANTEES.md Row 11's SCALAR_ATOMICS policy in foreign.rs.
  2. New soundness rejections on buggy .hy code (HYB-E3006 & O5.2): Code that previously exploited foreign.rs omissions — such as passing a const []byte destination buffer to hex.decode(const_buf, src) or mutating a []byte buffer while a sub-slice returned by bytes.split(buf, sep) is shared across a task — will now be rejected at compile time (HYB-E3006 / HYB-E3001). All 10 existing corpus examples (examples/corpus/*.hy) pass without modification.
  3. The Assembly / CGo / Reflection Boundary (Tier3): Functions implemented in .s assembly (e.g., bytes.IndexByte, crypto/aes assembly routines) or reflect have no Go AST body showing element stores. For those ~5% of functions, the synthesizer must either read Go SSA/export data or fall back to Tier3_Interface_Or_Asm_Conservative (requiring a 1-line override only when a bodyless .s function takes a dst []byte parameter that is actually read-only).
