Unconservative ACI 318-19 Shear & P–M Interaction Checks in rc_check and certify_rc_members

Bounty submission for #505.

Metadata

  • Target Repository: lambdaclass/stabileo (engine/)
  • Severity: Critical (per docs/SAFETY_ADVISORIES.md: "Unconservative by more than 10 % in a governing quantity, in a default workflow or a common model, with no warning" and "A check returns pass (ratio ≤ 1.0) or certified_ok = true on a member that should fail by more than 10%")
  • Affected Files & Symbols:
    1. engine/src/postprocess/rc_check.rs:
      • shear_capacity (lines 400–449)
      • check_single_rc_member (line 197)
      • interaction_point (lines 322–347)
    2. engine/src/certify/design.rs:
      • rc_ratio_enclosures (line 899)
      • interaction_moment_enclosure (lines 821–861)
      • certify_rc_members (lines 923–931; exported to WASM at engine/src/lib.rs)

1. Executive Summary

Both the ACI 318-19 design checker (check_rc_members) and its interval-certified counterpart (certify_rc_members) share generic routines in engine/src/postprocess/rc_check.rs that contain four compounding unconservative defects:

  1. Axial Tension (f.nu > 0) Is Completely Ignored in Concrete Shear Capacity Vc (ACI 318-19 Table 22.5.5.1 & §22.5.5.1.1):
    RCDesignForces provides nu: Option<f64> (tension-positive), and check_single_rc_member / rc_ratio_enclosures use nu for flexure and axial checks, but shear_capacity<T: Real>(m: &RCMemberData) -> T does not accept nu at all. Under ACI 318-19 Table 22.5.5.1 and §22.5.5.1.1, axial force modifies $V_c$ by $+N_{u,\text{ACI}} / (6 A_g) \cdot b_w d$ (where $N_{u,\text{ACI}} = -\text{nu}$ is negative in tension), reducing $V_c$ down to $0$ when tensile stress $\text{nu} / A_g \ge 6 \times 0.17\lambda\sqrt{f'_c} = 1.02\lambda\sqrt{f'c}$ (and capping $N{u,\text{ACI}} / (6 A_g) \le 0.05 f'_c$ and $V_c \le 0.42\lambda\sqrt{f'_c} b_w d$ in compression per §22.5.5.1.2). Unlike cirsoc201_check.rs (lines 486–499) and ec2_check.rs (lines 236–251), rc_check.rs credits 100% of the uncracked concrete shear capacity $V_c$ even when the section is in full axial tension.

  2. Missing fyt <= 420 MPa Cap on Stirrup Yield Strength in Vs (ACI 318-19 Table 20.2.2.4(a) & §22.5.3.3):
    Line 410 computes vs = (T::exact(av) * T::exact(m.fy) * T::exact(m.d)).dv(T::exact(s)) using m.fy uncapped. Per ACI 318-19 Table 20.2.2.4(a) and §22.5.3.3, the value of $f_{yt}$ used to calculate $V_s$ shall not exceed $420\text{ MPa}$. (This cap was implemented in cirsoc201_check.rs:467 per docs/verification/TS_ENGINE_LOGIC.md line 161, but left unfixed in rc_check.rs.) For $500\text{ MPa}$ or Grade 80 ($550\text{ MPa}$) reinforcement, rc_check.rs overstates $V_s$ by +19.0% and +31.0%, respectively.

  3. Missing sqrt(f'c) <= 8.3 MPa Cap on vc_with_min, av_min_mm2, and vs_max (ACI 318-19 §22.5.3.1):
    Line 405 computes let sqrt_fc = fc_mpa.sqrt(); uncapped and only applies .min(T::lit(8.3)) inside vc_without_min (line 429). It leaves vc_with_min (line 415), av_min_mm2 (line 435), and vs_max = 0.66 * sqrt_fc * bw_mm * d_mm (line 445) uncapped for $f'_c &gt; 69\text{ MPa}$, violating ACI 318-19 §22.5.3.1 (which caps $\sqrt{f'c} \le 8.3\text{ MPa}$ on $V{s,\max}$ unconditionally and on $V_c$ unless special §22.5.3.2 beam/joist web reinforcement is provided).

  4. Displaced Concrete Mis-Accounting in P–M Interaction (interaction_point, lines 335–343):

    • For the compression steel layer at $d'$, line 336 unconditionally subtracts displaced concrete: let cs = as_comp * (fs_comp - T::lit(0.85) * fc); even when $c &lt; d'$ ($\varepsilon'_s &lt; 0$, i.e. top steel is in the tension zone and displaces no compressed concrete; contrast rc_flexure.rs:80 which branches on zero.le(eps_sc)).
    • Conversely, for the tension steel layer at $d$, line 341 computes let t = T::exact(m.as_tension) * fs_tens; without deducting displaced concrete $0.85 f'c A_s$ when $c > d$ ($\varepsilon_t < 0$, bottom steel in compression under high axial load; contrast cirsoc201_check.rs:375). As a result, at large neutral axis depths $c > d$, $\phi P_n(c)$ in interaction_point exceeds the theoretical squash load $\phi P_o = 0.65 [0.85 f'c (A_g - A{st}) + f_y A{st}]$.

2. Vulnerable Code

In engine/src/postprocess/rc_check.rs:

// Line 197: f.nu is never passed to shear_capacity
let phi_vn: f64 = shear_capacity(m);
// Lines 334-343:
// Compression steel: net of the concrete it displaces (even when c < d' and steel is in tension!)
let fs_comp = (strain_at(d_prime) * es).max(-fy).min(fy);
let cs = as_comp * (fs_comp - T::lit(0.85) * fc);

// Tension steel: positive strain_at means compression, so flip (never deducts 0.85*fc when c > d!)
let epsilon_t = -strain_at(d);
let fs_tens = (epsilon_t * es).max(-fy).min(fy);
let t = T::exact(m.as_tension) * fs_tens;
// Lines 400-449:
pub(crate) fn shear_capacity<T: Real>(m: &RCMemberData) -> T {
    let lambda = T::exact(m.lambda.unwrap_or(1.0));
    let fc_mpa = T::exact(m.fc).dv(T::exact(1e6));
    let bw_mm = T::exact(m.b) * T::exact(1000.0);
    let d_mm = T::exact(m.d) * T::exact(1000.0);
    let sqrt_fc = fc_mpa.sqrt(); // <-- Uncapped above 8.3 MPa

        _ => zero,
    };

    // ACI 318-19 9.6.3.4: Av,min = max(0.062*sqrt(f'c)*bw*s/fyt, 0.35*bw*s/fyt)
    let vc_with_min = || T::lit(0.17) * lambda * sqrt_fc * bw_mm * d_mm; // <-- Ignores Nu/(6*Ag) and 8.3 MPa cap!

    let vs = vs.min(vs_max);

}

3. Proof of Concept / Reproduction

Case 1: RC Member Under Axial Tension + Shear (check_rc_members & certify_rc_members)

Consider a standard rectangular RC member ($b = 0.30\text{ m}$, $h = 0.50\text{ m}$, $d = 0.44\text{ m}$, $d' = 0.06\text{ m}$, $A_g = 0.15\text{ m}^2$, $f'_c = 28\text{ MPa}$, $f_y = 500\text{ MPa}$, $A_s = A'_s = 1500\text{ mm}^2$, 2-leg $\varnothing 10$ stirrups $A_v = 157\text{ mm}^2$ at $s = 0.20\text{ m}$) subjected to:

  • Factored axial tension nu = 350_000.0 N ($350\text{ kN}$ tension, so $N_{u,\text{ACI}} = -350\text{ kN}$ and axial stress $N_{u,\text{ACI}} / A_g = -2.333\text{ MPa}$)
  • Factored shear vu = 200_000.0 N ($200\text{ kN}$)
  • Factored moment mu = 50_000.0 N·m ($50\text{ kN}\cdot\text{m}$)

1. True ACI 318-19 Calculation:

  • By Table 22.5.5.1(a) and §22.5.5.1.1:

$$V_c = \max\left(0,; \left(0.17\lambda\sqrt{f'_c} + \frac{N_{u,\text{ACI}}}{6 A_g}\right) b_w d\right) = (0.17\sqrt{28} - 0.3889)\times 300 \times 440 = 67.41\text{ kN}$$

  • By Table 20.2.2.4(a) and §22.5.3.3 ($f_{yt} = \min(500, 420) = 420\text{ MPa}$):

$$V_s = \frac{157 \times 420 \times 440}{200} = 145.07\text{ kN}$$

  • Design shear capacity:

$$\phi V_n = 0.75 (67.41 + 145.07) = 159.36\text{ kN}$$

  • True shear utilization:

$$\frac{V_u}{\phi V_n} = \frac{200.0}{159.36} = 1.2550 > 1.0 \quad (\text{FAIL})$$

2. Stabileo check_rc_members & certify_rc_members Output:

  • Ignores nu in $V_c$, computing $V_c = 0.17\sqrt{28}\times 300\times 440 = 118.74\text{ kN}$ (+76.1% too high).
  • Uses uncapped $f_y = 500\text{ MPa}$ in $V_s$, computing $V_s = 172.70\text{ kN}$ (+19.0% too high).
  • Reports $\phi V_n = 0.75(118.74 + 172.70) = 218.58\text{ kN}$ (+37.2% unconservative overstatement).
  • Reports shear_ratio = 0.9150 <= 1.0, unity_ratio = 0.9150 <= 1.0, and certify_rc_members returns certified: true, certified_ok: true, certified_fail: false.
  • (Note: at higher axial tension nu >= 810 kN without stirrups, ACI 318-19 requires $V_c = 0$, whereas Stabileo reports $\phi V_n = 89.06\text{ kN}$ and certified_ok: true on a member with zero shear capacity.)

4. Recommended Fix

  1. Update shear_capacity<T: Real>(m: &RCMemberData, axial_compression: T) -> T to:
    • Cap sqrt_fc = fc_mpa.sqrt().min(T::lit(8.3)) globally per ACI 318-19 §22.5.3.1 (as in cirsoc201_check.rs:460).
    • Cap fyt_vs = m.fy.min(420e6) in $V_s$ per ACI 318-19 §20.2.2.4 / §22.5.3.3 while keeping actual m.fy in $A_{v,\min}$ (as in cirsoc201_check.rs:467–472).
    • Include the axial stress term axial = (axial_compression / (ag * 1e6) / 6.0).min(0.05 * fc_mpa) in $V_c$, clamped to [0.0, 0.42 * lambda * sqrt_fc * bw_mm * d_mm] per ACI 318-19 Table 22.5.5.1, §22.5.5.1.1, and §22.5.5.1.2, and pass -nu from check_single_rc_member and rc_ratio_enclosures.
  2. In interaction_point, only deduct displaced concrete $0.85 f'_c$ when a steel layer is in compression (branch(zero.le(strain_at(d_prime)), ...) for compression steel, and deduct 0.85 * fc from the tension steel when epsilon_t < 0).
