Cómo funciona

Cliente reserva. Tú recibes. Auto-reminder.

# 1. Configura profesionales y servicios (una sola vez) citaya add-professional --id DR01 --name "Dra. García" --specialty "Dermatología" citaya add-service --id SRV01 --name "Consulta" --duration 30 --price 50 # 2. Tu cliente reserva vía API pública (widget en tu web): curl -X POST http://localhost:8005/public/book -d '{ "professional_id": "DR01", "service_id": "SRV01", "customer_name": "Juan Pérez", "customer_phone": "593999123456", "customer_email": "juan@x.com", "start_at": "2026-10-26T10:00" }' # Response: { "id": "APT-A1B2C3D4", "professional_id": "DR01", "service_name": "Consulta", "start_at": "2026-10-26T10:00:00", "end_at": "2026-10-26T10:30:00", "status": "confirmed" } # 3. Cliente recibe email de confirmación instantáneo # 4. 2 horas antes de la cita: recordatorio automático # 5. Tú gestionas todo desde CLI o API admin: citaya list-appointments --date-from 2026-10-26 # → APT-A1B2C3D4 | 26/10 10:00 | Dra. García | Juan Pérez | confirmed citaya cancel APT-A1B2C3D4
