Cómo funciona

Pega la reseña. Recibe 3 respuestas.

# 1. Reseña negativa de Google Reviews curl -X POST http://localhost:8006/v1/generate \ -H "Content-Type: application/json" \ -d '{ "platform": "google_reviews", "rating": 1, "text": "Servicio pésimo, demoraron 1 hora en atendernos. La comida fría.", "author_name": "Pedro Ramírez" }' # Response: { "review_summary": "Cliente menciona servicio lento y comida fría", "detected_sentiment": "negative", "suggestions": [ { "text": "Hola Pedro. Lamentamos tu experiencia. Escríbenos a contacto@... para solucionarlo.", "tone": "corto", "word_count": 12 }, { "text": "Hola Pedro. Lamentamos mucho que tu experiencia con servicio no haya sido la esperada...", "tone": "medio", "word_count": 65 }, { "text": "Hola Pedro. Leímos tu reseña y sentimos mucho que no hayas tenido la experiencia que esperabas respecto a servicio...", "tone": "detallado", "word_count": 150 } ], "model_used": "glm-4.6" } # 2. Sin AI? Modo template (gratis forever): curl -X POST "http://localhost:8006/v1/generate?mode=template" \ -d '{"rating":1,"text":"Pesimo","author_name":"Pedro"}'
