Cómo funciona

Topic in. Posts + calendar out.

# 1. Generar 3 variantes de post (template mode, gratis) postfactory generate "marketing digital" \ --platform instagram \ --type educational \ --variations 3 \ --mode template # Output: Modelo: template-fallback Variación 1 (45w, 312c) ¿Sabías que marketing digital? 🤔 Tu contenido necesita un CTA claro La audiencia se construye con valor El storytelling vende más que las features Link en bio 🔗 #marketing #marketingdigital #redessociales #contentmarketing #seo Best time: 07:00-09:00 # 2. Generar calendario 7 días: postfactory calendar --days 7 --platforms "instagram,linkedin" # Output: 📅 Calendario de contenido (7 días) | Fecha | Día | Tema | Tipo | Plataformas | |----------|-----------|--------------------|---------------|-------------------------------| | 26/10 | Monday | consejo del día... | educational | instagram@07:00-09:00, ... | | 27/10 | Tuesday | tendencia en... | promotional | ... | # 3. Solo hashtags: postfactory hashtags "fitness motivation" --niche fitness --platform instagram # → #fitnessmotivation #fitness #gym #workout ... (15 tags) # 4. Vía API: curl -X POST "http://localhost:8007/v1/generate?mode=ai" \ -d '{"topic":"productividad","platform":"linkedin","content_type":"how_to","variations":3}'
