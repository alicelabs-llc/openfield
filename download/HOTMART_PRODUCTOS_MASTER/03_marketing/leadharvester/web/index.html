Features

Todo lo que necesitas para
generar listas de leads

🎯

3 modos de scraping

Por username individual, hashtag (top perfiles), o followers de cuenta competidora. Filtra solo negocios.

📧

Emails y teléfonos

Detecta emails ocultos con obfuscaciones ([at], [dot], [ar]). Teléfonos con country code. URLs externas.

🏷️

Categorización auto

9 categorías: restaurante, moda, fitness, belleza, tecnología, marketing, inmobiliaria, salud, educación.

💼

Filtro business

Identifica perfiles comerciales por heurísticas (venta, tienda, DM, envío, etc.). Filtra ruido de perfiles personales.

📊

3 formatos de export

CSV plano, Excel con hoja Summary (métricas agregadas), JSON para integraciones API.

🤖

API REST async

Inicia jobs asíncronos, poll por estado, descarga cuando terminen. Integrable con tu CRM.

Cómo funciona

Una URL. Una lista de leads.
