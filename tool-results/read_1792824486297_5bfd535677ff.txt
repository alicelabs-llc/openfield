   208→   687→**Insertion script (single output PDF):**
   209→   688→```python
   210→   689→from pypdf import PdfReader, PdfWriter
   211→   690→
   212→   691→A4_W, A4_H = 595.28, 841.89  # A4 in points
   213→   692→
   214→   693→def normalize_page_to_a4(page):
   215→   694→    """Scale a page to A4 if its dimensions don't match."""
   216→   695→    box = page.mediabox
   217→   696→    w, h = float(box.width), float(box.height)
   218→   697→    if abs(w - A4_W) > 2 or abs(h - A4_H) > 2:
   219→   698→        page.scale_to(A4_W, A4_H)
   220→   699→    return page
   221→   700→
   222→   701→def insert_cover(cover_pdf, body_pdf, output_pdf):
   223→   702→    """Insert cover as first page of body PDF → single output file."""
   224→   703→    writer = PdfWriter()
   225→   704→    # Cover as page 1
   226→   705→    cover_page = PdfReader(cover_pdf).pages[0]
   227→   706→    writer.add_page(normalize_page_to_a4(cover_page))
   228→   707→    # Body pages follow
   229→   708→    for page in PdfReader(body_pdf).pages:
   230→   709→        writer.add_page(normalize_page_to_a4(page))
   231→   710→    writer.add_metadata({'/Title': 'Report Title', '/Author': 'Z.ai', '/Creator': 'Z.ai'})
   232→   711→    with open(output_pdf, 'wb') as f:
   233→   712→        writer.write(f)
   234→   713→```

You must call `normalize_page_to_a4()` to unify dimensions before insertion.

   242→   721→**Cover design rules (summary - see cover.md for details):**
   243→   722→- Page size: `width: 794px; height: 1123px` (A4 at 96dpi)

   247→   726→- Primary color used only for text, lines, geometric accents - never as large-area background
   248→   727→- Sophistication = whitespace + typography + restrained geometric accents

   250→   729→**Cover Constitution (5-Layout System):**
   251→   730→- **Pick a layout (01/03/04/06/07)** from `typesetting/cover.md` that matches the document tone. No global default - every selection must be a deliberate design decision.
   252→   731→- **Maximum 4 components** on any cover. Typical recipe: Title + subtitle + 1 geometric accent + metadata.
   253→   732→- **Typography Scale**: Title ≈ 45pt, Subtitle ≈ 25pt, Meta ≥ 18pt (never below 14pt). Tiny text = FAIL.
   254→   733→- **Background layer (optional)**: See `typesetting/cover-backgrounds.md` for 3 recipes (A=极简弧线, B=工程十字轴+立柱, C=锐角切割+出血文字). Background renders BELOW all foreground content at 2-5% opacity.

   256→   735→- **Bounding Box spatial dispersion**: Group elements into 2-3 bounding boxes at opposite regions (e.g., top-left + bottom-right). Never cluster everything into middle 40%.
   257→   736→- **Safe Zone**: 12% top/bottom, 14% left/right padding on cover pages.
   258→   737→- **No body text on cover**: Cover = title + subtitle + date + optional geometric decoration. All content goes to page 2+.

   288→   767→### Standard Table Color Scheme (MUST USE for ALL tables)
   289→   768→
   290→   769→> **Colors MUST come from the `palette.cascade` output (Step 2).** The values below are variable names - they are populated by the cascade palette, never hardcoded.
   291→   770→
   292→   771→```python
   293→   772→# Colors from palette.cascade (Step 2) — NEVER hardcode hex values
   294→   773→# Table header uses HEADER_FILL (M tier, S ≤ 0.30) — NOT ACCENT (XS tier, too vivid)
   295→   774→TABLE_HEADER_COLOR = HEADER_FILL          # M tier — low-sat, blends with document body
   296→   775→TABLE_HEADER_TEXT  = colors.white          # White text for header (fixed)
   297→   776→TABLE_ROW_EVEN     = colors.white          # White for even rows
   298→   777→TABLE_ROW_ODD      = TABLE_STRIPE          # L tier — very subtle same-hue stripe
   299→   778→```
   300→   779→
   301→   780→> **⚠️ Why NOT `ACCENT` for table headers?** `ACCENT` is XS tier (S = 0.50-0.75), designed for tiny elements like badges and tags. Table headers occupy 5-20% of visual area (M tier). Using high-saturation `ACCENT` on table headers creates jarring color blocks that clash with the low-saturation body. `HEADER_FILL` (S ≤ 0.30) is specifically designed for this area ratio.

   303→   782→### Table Rules
   304→   783→- Caption must be centered, added immediately after the table
   305→   784→- Entire table must be centered on the page
   306→   785→- **Header Row**: Dark background (from palette `HEADER_FILL`, M tier), white bold text
   307→   786→- **Cell Margins**: Left/Right at least 120-200 twips
   308→   787→- **Alignment**: Each body element within the same table must be aligned the same method
   309→   788→- **Color consistency**: All tables in one PDF must use the same `HEADER_FILL` + `TABLE_STRIPE` scheme
   310→   789→- **Spacing**: `Spacer(1, 18)` → Table → `Spacer(1, 6)` → Caption → `Spacer(1, 18)`
   311→   790→
   312→   791→### Table Centering Enforcement (MANDATORY)
   313→   792→
   314→   793→**Every table MUST be horizontally centered on the page. No exceptions.**
   315→   794→
   316→   795→```python
   317→   796→# ReportLab: ALWAYS set hAlign='CENTER'
   318→   797→table = Table(data, colWidths=col_widths, hAlign='CENTER')
   319→   798→
   320→   799→# Width rule: table total width should be 85-100% of available content width
   321→   800→available_width = doc.width  # or page_width - left_margin - right_margin
   322→   801→table_width = sum(col_widths)
   323→   802→if table_width < available_width * 0.85:
   324→   803→    # Scale up columns proportionally to fill space
   325→   804→    scale = (available_width * 0.90) / table_width
   326→   805→    col_widths = [w * scale for w in col_widths]
   327→   806→
   328→   807→# ❌ WRONG — no hAlign (defaults to LEFT, table drifts left)
   329→   808→table = Table(data, colWidths=[100, 200, 150])
   330→   809→
   331→   810→# ✅ RIGHT — explicit centering
   332→   811→table = Table(data, colWidths=[100, 200, 150], hAlign='CENTER')
   333→   812→```

   425→   904→### Table Width Management (⚠️ Prevent Table Overflow)
   426→   905→
   427→   906→**Most common table bug: columns overflow the right page margin because colWidths are hardcoded without checking available space.**
   428→   907→
   429→   908→**Iron Rule: The sum of all colWidths MUST NOT exceed `available_width`.**
   430→   909→
   431→   910→```python
   432→   911→from reportlab.lib.pagesizes import A4
   433→   912→from reportlab.lib.units import inch
   434→   913→
   435→   914→page_width = A4[0]  # 595.28pt
   436→   915→left_margin = 1.0 * inch   # 72pt (adjust to your doc's actual margins)
   437→   916→right_margin = 1.0 * inch  # 72pt
   438→   917→available_width = page_width - left_margin - right_margin  # ≈ 451pt
   439→   918→
   440→   919→# ─── Method 1: Proportional widths (RECOMMENDED) ───
   441→   920→# Define column ratios, auto-scale to fit available_width
   442→   921→col_ratios = [0.25, 0.40, 0.20, 0.15]  # must sum to 1.0
   443→   922→col_widths = [r * available_width for r in col_ratios]
   444→   923→table = Table(data, colWidths=col_widths)
   445→   924→
   446→   925→# ─── Method 2: Fixed + flex columns ───
   447→   926→# Some columns have fixed width (numbers, dates), rest fills remaining space
   448→   927→fixed_cols = {0: 80, 3: 60}  # col 0 = 80pt, col 3 = 60pt
   449→   928→fixed_total = sum(fixed_cols.values())
   450→   929→flex_count = 4 - len(fixed_cols)  # total columns minus fixed
   451→   930→flex_width = (available_width - fixed_total) / flex_count
   452→   931→col_widths = []
   453→   932→for i in range(4):
   454→   933→    col_widths.append(fixed_cols.get(i, flex_width))
   455→   934→table = Table(data, colWidths=col_widths)
   456→   935→
   457→   936→# ─── Method 3: Let ReportLab auto-calculate (simplest, less control) ───
   458→   937→# Pass colWidths=None - ReportLab auto-sizes based on content
   459→   938→# ⚠️ Risk: may still overflow if content is too wide
   460→   939→table = Table(data)  # no colWidths
   461→   940→```
   462→   941→
   463→   942→**Checklist before adding any table:**
   464→   943→1. Calculate `available_width` from your actual page size and margins
   465→   944→2. Sum all colWidths - must be ≤ `available_width`
   466→   945→3. For CJK text: characters are wider than Latin - budget ~12pt per CJK char at 10pt font
   467→   946→4. If a column has long text (descriptions, policies), use Paragraph() wrapping inside cells (not plain strings) - plain strings don't wrap and will overflow
   468→   947→5. Test with the longest expected content in each column
   469→   948→

   487→   966→```
   488→   967→
   489→   968→| Requirement | DocTemplate | Build Method |
   490→   969→|-------------|-------------|--------------|
   491→   970→| Multi-page with TOC | `TocDocTemplate` | `multiBuild()` |
   492→   971→| Single-page or no TOC | `SimpleDocTemplate` | `build()` |
   493→   972→| With Cross-References (no TOC) | `SimpleDocTemplate` | `build()` |
   494→   973→| Both TOC + Cross-References | `TocDocTemplate` | `multiBuild()` |
   495→   974→
   496→   975→**⚠️ CRITICAL**:
   497→   976→- `multiBuild()` is ONLY needed when using `TableOfContents`
   498→   977→- Using `build()` with `TocDocTemplate` = TOC won't work
   499→   978→- Using `multiBuild()` without `TocDocTemplate` = unnecessary overhead

   529→  1008→## Auto-Generated Table of Contents
   530→  1009→
   531→  1010→### ❌ FORBIDDEN: Manual Table of Contents
   532→  1011→**NEVER manually create TOC with hardcoded page numbers.**
   533→  1012→
   534→  1013→### ⚠️ MANDATORY: TOC requires a cover page
   535→  1014→**Unless the user explicitly requests no cover, if a document has a Table of Contents, it MUST have a cover page.** Structure: Cover (page 1) → TOC (page 2) → Content (page 3+). Do not generate a TOC without a preceding cover page.
   536→  1015→
   537→  1016→### ✅ ALWAYS use auto-generated TOC:
   538→  1017→
   539→  1018→```python
   540→  1019→from reportlab.platypus import SimpleDocTemplate, Paragraph, PageBreak, Spacer
   541→  1020→from reportlab.platypus.tableofcontents import TableOfContents
   542→  1021→from reportlab.lib.utils import simpleSplit
   543→  1022→import hashlib
   544→  1023→
   545→  1024→class TocDocTemplate(SimpleDocTemplate):
   546→  1025→    def afterFlowable(self, flowable):
   547→  1026→        if hasattr(flowable, 'bookmark_name'):
   548→  1027→            level = getattr(flowable, 'bookmark_level', 0)
   549→  1028→            text = getattr(flowable, 'bookmark_text', '')
   550→  1029→            key = getattr(flowable, 'bookmark_key', '')
   551→  1030→            # MUST pass key as 4th element - without it, TOC entries won't have clickable links
   552→  1031→            self.notify('TOCEntry', (level, text, self.page, key))
   553→  1032→
   554→  1033→doc = TocDocTemplate("document.pdf", pagesize=letter)
   555→  1034→story = []
   556→  1035→
   557→  1036→toc = TableOfContents()
   558→  1037→toc.levelStyles = [
   559→  1038→    ParagraphStyle(name='TOCHeading1', fontSize=14, leftIndent=20, fontName='FreeSerif'),
   560→  1039→    ParagraphStyle(name='TOCHeading2', fontSize=12, leftIndent=40, fontName='FreeSerif'),
   561→  1040→]
   562→  1041→story.append(Paragraph("<b>Table of Contents</b>", styles['Title']))
   563→  1042→story.append(toc)
   564→  1043→story.append(PageBreak())
   565→  1044→
   566→  1045→def add_heading(text, style, level=0):
   567→  1046→    # Generate a unique bookmark key for this heading
   568→  1047→    key = 'h_%s' % hashlib.md5(text.encode()).hexdigest()[:8]
   569→  1048→    p = Paragraph('<a name="%s"/>%s' % (key, text), style)
   570→  1049→    p.bookmark_name = text
   571→  1050→    p.bookmark_level = level
   572→  1051→    p.bookmark_text = text
   573→  1052→    p.bookmark_key = key  # This key enables clickable TOC links
   574→  1053→    return p
   575→  1054→
   576→  1055→# ⚠️ Orphan Heading Prevention (NOT a page break rule)
   577→  1056→# If an H1 heading would appear in the bottom 15% of the page with no room
   578→  1057→# for at least a few lines of content, push it to the next page.
   579→  1058→# This is NOT "every H1 starts a new page" — it only triggers when the heading
   580→  1059→# would be orphaned at the very bottom.
   581→  1060→available_height = A4[1] - top_margin - bottom_margin
   582→  1061→H1_ORPHAN_THRESHOLD = available_height * 0.15  # ~100pt ≈ 3.5cm — enough for heading + 2 lines
   583→  1062→
   584→  1063→def add_major_section(text, style):
   585→  1064→    """Add an H1-level heading with orphan prevention (NOT forced page break)."""
   586→  1065→    return [
   587→  1066→        CondPageBreak(H1_ORPHAN_THRESHOLD),  # Only break if heading would be orphaned at page bottom
   588→  1067→        add_heading(text, style, level=0),
   589→  1068→    ]
   590→  1069→
   591→  1070→story.extend(add_major_section("Chapter 1: Introduction", styles['Heading1']))
   592→  1071→# ... content ...
   593→  1072→
   594→  1073→doc.multiBuild(story)  # MUST use multiBuild for TOC
   595→  1074→```
   596→  1075→
   597→  1076→**⚠️ CRITICAL TOC LINK RULES:**
   598→  1077→1. `afterFlowable` MUST pass `key` as the 4th element in the notify tuple - without it, TOC entries have no clickable links
   599→  1078→2. `add_heading` MUST set `bookmark_key` AND embed `<a name="key"/>` in the Paragraph text - this creates the link destination
   600→  1079→3. The key must be unique per heading - use a hash of the heading text
   601→  1080→
