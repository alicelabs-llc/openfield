FAQ

Preguntas frecuentes

¿Necesito API keys de Google, VirusTotal o IPQS?

No. ScamShield Pro funciona 100% out-of-the-box con blocklists públicos gratuitos (URLHaus, ip-api.com). Si quieres enriquecer con Google Safe Browsing, VirusTotal o IPQualityScore, son opcionales — las free tiers de cada una son suficientes para la mayoría de usuarios.

¿Cuánto tarda un scan?

Entre 1-3 segundos por URL en condiciones normales, dependiendo del tiempo de respuesta del sitio analizado. Los checks corren en paralelo (fase 1) y luego content analysis (fase 2). El cache DiskCache integrado reduce drásticamente repeticiones.

¿Puedo usar esto en producción?

Sí. ScamShield Pro está pensado para producción: rate limiting por IP, cache TTL configurable, Docker ready, healthcheck endpoint. En producción tras un reverse proxy (Caddy/Nginx) con TLS termina siendo una API robusta.

¿Puedo revenderlo como SaaS?

El plan Agency ($197) permite marca blanca completa: pon tu logo, tu dominio, tu pricing. Pero no puedes revender ScamShield Pro como producto standalone que compita con el original. Si quieres distribución OEM o revenue-share, escríbenos a eddyflores100@gmail.com.

¿Funciona sin internet?

No, necesita conexión para hacer lookups DNS, WHOIS, HTTP, SSL. Pero los datos de tus usuarios NO salen de tu servidor. Las únicas conexiones salientes son: el sitio que estás analizando + los blocklists públicos (IP y dominio analizado).

¿Qué incluye el código?

9 detectores (domain age, SSL, DNS, TLD, redirect chain, content, phishing, blocklist, IP reputation), FastAPI server, CLI Click, dashboard HTML, tests con pytest, Dockerfile, docker-compose, 3 ejemplos prácticos, y docs completas (arquitectura, API, competidores, pricing). Total: ~2500 líneas de código.
