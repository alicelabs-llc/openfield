# EVALS.md — Verificación del agente por escenarios (ZOLO v6.0)

> Suite de verificación del agente. Ejecutar: (1) tras montar el agente en un entorno nuevo, (2) tras CADA modificación de `ZOLO_V6.md`, (3) en la auditoría periódica de mejora continua (§15), (4) en el mantenimiento mensual (2-3 evals aleatorios).
> **v3.0 — dos niveles** (Anthropic demystifying-evals): E01-E52 = suite de REGRESIÓN (deben pasar consistentemente; verificación pass^k: 3 intentos); la suite de CAPABILITY se alimenta de fallos reales del usuario → cada fallo nuevo produce 1 eval de capability. Grader determinista primero (exit code, grep, HTTP); LLM-judge solo para lo subjetivo, aislado por dimensión, con escape "Unknown". **Un eval al 0% = EVAL ROTO — investigar el grader antes que el modelo.** (v6.0: el grader determinista también aplica a la maquinaria — `zolo_auditar_skills.py` exit 0 = E52 verde.)
